# 🏏 IPL Stat Assistant

A conversational assistant for IPL statistics. It puts a LangChain **pandas DataFrame agent** on top of ball-by-ball IPL data (2008–2026) so you can ask questions in plain English, and adds visual **match summaries**, **momentum charts**, and **auto-charted answers**.

![Sample](sample.jpeg)

## Features

- **Ask anything in natural language** — the agent writes and runs pandas queries against the ball-by-ball data (read-only, sandboxed prompt rules).
- **Multi-provider LLM** — one **OpenRouter** key reaches OpenAI, Anthropic and Gemini models; plus native **Gemini** (Google AI Studio key) and **Groq**.
- **Match Summary & Charts** — pick any match to get a compact card (totals, extras, boundaries, top batters, phase splits, runs/over sparkline).
- **Headline** — a rule-based 2–3 line summary of each match (result, standout performer, turning point). No LLM tokens.
- **Momentum worm** — a cumulative-runs curve per innings with **momentum-shift overs** marked (collapse = 2+ wickets in an over, surge = the biggest over).
- **Auto-charts** — when an answer contains a numeric table, it is rendered as a bar chart automatically.
- **Lightweight conversation memory** — recent turns are replayed (trimmed) so follow-up questions keep context without heavy token cost.
- **Multiple chats + export** — keep parallel chat histories and export any chat to JSON.

## Quickstart

Requires **Python 3.11+**.

```bash
# with uv (recommended)
uv sync
uv run streamlit run app.py

# or with pip
pip install -e .
streamlit run app.py
```

Then open the local URL Streamlit prints, choose a provider in the sidebar, and paste the matching API key.

### API keys

| Provider | Where to get a key | Notes |
|----------|--------------------|-------|
| OpenRouter | https://openrouter.ai/keys | One key → OpenAI / Anthropic / Gemini models. Free/limited balances work (completions are capped to fit). |
| Gemini | https://aistudio.google.com/apikey | Native Google Gemini models. |
| Groq | https://groq.com | Fast, generous free tier. |

Keys are entered in the sidebar at runtime and are never written to the repo.

## Data

Ball-by-ball IPL data from the Kaggle dataset [`chaitu20/ipl-dataset2008-2025`](https://www.kaggle.com/datasets/chaitu20/ipl-dataset2008-2025), fetched and cleaned by `load_and_clean_df.py` (team-name normalisation, typed columns, derived fields, and a per-column description dictionary). Data currently runs through the **16-04-2026** PBKS vs MI match. Responses reflect that snapshot and may not include newer matches.

## Project structure

| File | Role |
|------|------|
| `app.py` | Streamlit UI, provider/LLM wiring, agent, chat, and the Match Summary panel. |
| `load_and_clean_df.py` | Loads and cleans the Kaggle dataset into the working DataFrame. |
| `match_summary.py` | Pure functions: match listing, summary card, headline, momentum shift points, and markdown-table → chart parsing. |

## Roadmap
